Cambiar contraseña de acceso

Renovar la clave de GitHub (solo cuando venza)
  1. Entra a github.com/settings/personal-access-tokens/new (inicia sesión con la cuenta MrKardona).
  2. En Token name pon: panel-mymstore. En Expiration elige 1 año.
  3. En Repository access elige Only select repositories → marca mymstore.
  4. En Permissions → Repository permissions busca Contents y ponlo en Read and write.
  5. Botón verde Generate token, copia la clave que empieza por github_pat_, pégala arriba y pulsa Conectar.
  6. Pulsa Cambiar contraseña de acceso para guardarla en todos los dispositivos.

Esa clave es como la llave de la tienda: no la compartas ni la mandes por chat.
