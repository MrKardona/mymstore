¿Cómo creo mi clave? (una sola vez, 2 minutos)
  1. Entra a github.com/settings/personal-access-tokens/new (inicia sesión con la cuenta MrKardona).
  2. En Token name pon: panel-mymstore. En Expiration elige No expiration (o 1 año).
  3. En Repository access elige Only select repositories → marca mymstore.
  4. En Permissions → Repository permissions busca Contents y ponlo en Read and write.
  5. Botón verde Generate token, copia la clave que empieza por github_pat_ y pégala aquí arriba.

Esa clave es tu contraseña: no la compartas. Si la pierdes, generas otra igual.
